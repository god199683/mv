# MV 캐릭터 시트 작업실

노래와 가사의 흐름에 맞춰, 제공받은 캐릭터 시트를 일관되게 유지하는 뮤직비디오를 제작하는 공간입니다.

## 시작 순서

1. `assets/character-sheets/`에 캐릭터 시트를 넣습니다.
2. `assets/music/`에 음원을, `assets/lyrics/`에 가사를 넣습니다.
3. `prompts/scene-plan.md`에 가사 구간별 장면과 프롬프트를 작성합니다.
4. 생성한 클립과 최종본은 `output/`에 저장합니다.

## 제작 원칙

- 캐릭터의 얼굴, 헤어, 의상, 색상, 비율은 캐릭터 시트를 기준으로 유지합니다.
- 한 장면은 가사의 의미와 박자 변화가 함께 드러나도록 구성합니다.
- 모든 장면에서 화면비, 작화 스타일, 광원 방향을 사전에 통일합니다.
