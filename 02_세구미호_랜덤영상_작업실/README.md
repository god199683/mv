# 세 구미호 랜덤 카테고리 영상 작업실

캐릭터 이미지를 바탕으로 세 명의 구미호가 매회 무작위 카테고리에서 약 1분 동안 반응·대결·협업하는 짧은 영상을 제작하는 공간입니다.

## 시작 순서

1. `assets/characters/`에 세 구미호 캐릭터 이미지를 넣습니다.
2. `prompts/random-episode.md`에서 카테고리와 에피소드 구성을 정합니다.
3. 캐릭터별 클립을 생성하고 `output/`에 저장합니다.

## 기본 구성 (약 60초)

- 0–5초: 오늘의 랜덤 카테고리 공개
- 5–15초: 세 구미호의 첫 반응
- 15–45초: 각자 개성에 맞는 시도 또는 대결
- 45–55초: 반전 또는 가장 재미있는 결과
- 55–60초: 다음 에피소드를 위한 짧은 마무리

## 일관성 원칙

- 세 캐릭터의 외형, 꼬리 수·색·장식, 성격 역할을 고정합니다.
- 영상마다 카테고리만 바꾸고 캐릭터 관계와 세계관은 이어집니다.
