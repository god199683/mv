# Grok용 랜덤 에피소드 설계

## 카테고리 후보

- 요리 대결
- 인간 세계 체험
- 전통 설화 미션
- 패션 변신
- ASMR 소리 찾기
- 게임/운동 대결
- 비 오는 날의 소원
- 마법 상점 탐방

## 이번 회차

- 선택 카테고리: 
- 세 구미호 역할: 리더 / 장난꾸러기 / 차분한 해결사
- 화면비 및 작화 스타일: 

| 구간 | 내용 | 생성 프롬프트 |
| --- | --- | --- |
| 0–5초 | 카테고리 공개 | 세 구미호 캐릭터 이미지를 충실히 유지,  |
| 5–15초 | 첫 반응 |  |
| 15–45초 | 메인 미션 |  |
| 45–55초 | 결과/반전 |  |
| 55–60초 | 엔딩 |  |

## 공통 네거티브 프롬프트

캐릭터 수 변경, 꼬리 수 변경, 캐릭터 디자인 변경, 얼굴 왜곡, 손가락 오류, 텍스트, 워터마크

## Grok 입력 팁

세 구미호 이미지를 먼저 함께 첨부하고, 표의 각 구간을 하나씩 생성합니다. 모든 장면에 "첨부한 세 구미호의 외형과 꼬리 특징을 정확히 유지"를 넣어 캐릭터 일관성을 높입니다.
